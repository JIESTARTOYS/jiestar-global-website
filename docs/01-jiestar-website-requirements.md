\# JIESTAR Global Website Requirements



\## 1. Project Background



JIESTAR needs to rebuild its official website for the global market.



The current domestic website feels more like a traditional factory website. It lacks international brand presentation, clear SEO structure, and a strong separation between B2B and DTC customer needs.



The new JIESTAR global website should not be just a basic product display website or a standard Shopify template store. It should become JIESTAR's official global brand hub.



The website needs to serve two major customer groups:



1\. DTC customers: building block fans, collectors, model enthusiasts, gift buyers, and family users.

2\. B2B customers: wholesalers, distributors, retailers, ecommerce sellers, private-label brands, custom product buyers, and long-term product development partners.



For the B2B side, the website should not only focus on wholesale. It should also clearly highlight:



\- Wholesale supply

\- OEM / ODM customization

\- Product co-development

\- Long-term product line cooperation

\- Sub-brand partnership

\- Global channel cooperation



JIESTAR has already developed multiple sub-brands through cooperation with different B2B customers. Therefore, the global website should position custom development, long-term cooperation, and sub-brand co-creation as key B2B selling points.



\---



\## 2. Website Positioning



The JIESTAR global website should be positioned as:



\- An international building block brand website

\- A B2B wholesale and custom cooperation gateway

\- A DTC ecommerce storefront

\- A long-term SEO content hub



One-sentence positioning:



JIESTAR's global website should serve as an international building block brand hub, supporting both direct-to-consumer shopping and B2B cooperation, including wholesale supply, custom product development, product co-creation, and long-term sub-brand partnerships.



\---



\## 3. Core Website Goals



The first version of the website should achieve the following goals:



1\. Build JIESTAR's official brand image in the global market.

2\. Present JIESTAR's building block product lines and product development capabilities.

3\. Allow DTC customers to browse products and complete purchases.

4\. Attract B2B customers for wholesale inquiries.

5\. Attract custom product buyers for OEM / ODM cooperation.

6\. Attract long-term partners for product co-development and sub-brand cooperation.

7\. Build a foundation for long-term SEO content.

8\. Support traffic from TikTok, Instagram, YouTube, Reddit, Google Search, and other global channels.

9\. Keep the system simple and maintainable by one person.

\## 8. Technical Direction



Recommended technology stack:



\- Frontend: Next.js + TypeScript + Tailwind CSS

\- Ecommerce backend: Shopify

\- Content management: Markdown first, Sanity later if needed

\- Deployment: Vercel

\- Code management: GitHub

\- Development tools: Claude Code + Codex



Core principles:



\- Shopify handles transaction stability.

\- Next.js handles frontend design, layout freedom, and SEO.

\- Markdown / Sanity handles content.

\- Vercel handles deployment.

\- GitHub handles version control.

\- Claude Code / Codex improves development efficiency.



The first version should not build a fully custom ecommerce backend.

\- Customers with custom needs can clearly find the Custom Solutions page.
