\## 2. Navigation Logic



It is not recommended to use the following navigation structure in Version 1:



\- Wholesale

\- OEM / ODM

\- Brand Partnership



This may make the navigation too fragmented. New visitors may not clearly understand the difference between each entry.



Recommended structure:



\- Wholesale

\- Custom Solutions



Definition:



\- Wholesale = existing product wholesale, channel procurement, distributor cooperation

\- Custom Solutions = OEM / ODM, product customization, product co-development, sub-brand partnership



This structure is clearer and more suitable for an international brand website.
