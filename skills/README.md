# Project Skills

This directory stores reusable project-level AI skills for the JIESTAR global website and related commercial materials.

## Available Skills

### catalog-design

Use `skills/catalog-design/SKILL.md` when creating overseas product catalogs, brand brochures, distributor brochures, trade show brochures, product detail sheets, wholesale catalogs, PDF/PPTX catalog structures, Canva editable structures, Figma structures, Markdown outlines, or HTML catalog pages.

Supported invocation aliases:

- `/catalog-design`
- `/product-catalog`
- `/brochure-design`
- `/画册设计`
- `/产品画册`
- `/招商画册`

Standard input template:

- `skills/catalog-design/templates/standard-input-template.md`
